# Polices des images de partage

Utilisées uniquement par `src/app/opengraph-image.tsx` (l'aperçu affiché quand un lien
du site est partagé sur WhatsApp, Facebook, etc.). Le site lui-même charge ses polices
par `next/font`.

| Fichier              | Police                                     | Licence                   |
| -------------------- | ------------------------------------------ | ------------------------- |
| `newsreader-500.ttf` | Newsreader, graisse 500, taille optique 72 | SIL Open Font License 1.1 |
| `plex-mono-400.ttf`  | IBM Plex Mono, graisse 400                 | SIL Open Font License 1.1 |

Source : Google Fonts (instances statiques).
